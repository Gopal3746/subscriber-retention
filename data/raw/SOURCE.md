# Data source

This project uses the IBM Telco Customer Churn sample distributed publicly through Kaggle and mirrored in public GitHub repositories. The included CSV has 7,043 customer rows and 21 original columns.

Original Kaggle dataset name: **Telco Customer Churn** / IBM sample data.

Public mirror used to make this portfolio project reproducible:
`https://raw.githubusercontent.com/Nas-virat/Telco-Customer-Churn/refs/heads/main/Telco-Customer-Churn.csv`

Review the upstream dataset terms before any use beyond learning/portfolio analysis.
